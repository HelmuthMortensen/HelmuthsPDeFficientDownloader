## Helmuth's PDeFficient Downloader

A clever tool for downloading PDFs from an excel sheet (that has the columns "id", "url" and "alt url").

To install, install from requirements.txt into your Python virtual environment.

To see the avilable commands, use the Terminal and from the cli folder, input "python app.py"
